# Ishika Professional Salon & Spa

## Project Structure

- `index.html` - Complete single-page website entry point.
- `assets/css/style.css` - Global styles, responsive rules, and theme styling.
- `assets/js/main.js` - Navigation, theme toggle, animations, gallery lightbox, and booking behavior.
- `assets/images/hero/` - Hero image assets.
- `assets/images/gallery/` - Bridal portfolio images and gallery media.
- `assets/icons/` - Reserved for local icon assets.
- `assets/fonts/` - Reserved for locally hosted fonts when needed.
- `components/` - Reserved for reusable HTML fragments if the site is later split into multiple pages.
- `pages/` - Reserved for future standalone pages.
- `data/` - Structured salon content.
- `seo/` - `robots.txt` and `sitemap.xml`.

## Run Locally

Open `index.html` in a browser. No build process is required.

## Before Launch

Replace placeholder values such as `https://example.com/`, `+91 XXXXX XXXXX`, and the WhatsApp number with the salon's real production details.
